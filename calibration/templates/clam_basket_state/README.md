# Clam basket HUD template provenance

`closed_white_anchor.png` is a thresholded central 43×43 crop from
`tests/fixtures/clam_basket_state/75.png`. `open_dark_circle_anchor.png` is a grayscale
central 43×43 crop from `tests/fixtures/clam_basket_state/96.png`. Both
source fixtures were collected from the same Japanese Clam Blitz recording;
see the fixture README for provenance. They are development templates, not
independent validation samples. Coordinates assume the detector's 97×93
normalized HUD crop.
